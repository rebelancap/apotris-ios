# Updating to a new upstream Apotris release

The port is a thin overlay on pristine upstream: `vendor/apotris` is vendored
unmodified and pinned by commit (`upstream.pin`), and every change is a small
`#ifdef IOS`-gated patch in `overlay/patches/` (regenerated by
`scripts/gen-patches.py`, which **asserts the exact match count** of every edit
against the pristine source). That assertion is the safety net: if an upstream
release moves or rewrites a region we patch, `gen-patches.py` fails loudly
instead of silently producing a broken build.

## The process (when akouzoukos ships an update)

```bash
# 1. See what's new upstream
git -C vendor/apotris fetch origin
git -C vendor/apotris log --oneline HEAD..origin/main

# 2. Re-pin to the new commit
git -C vendor/apotris checkout <new-commit>
git -C vendor/apotris rev-parse HEAD > upstream.pin
git -C vendor/apotris submodule update --init   # in case subprojects moved

# 3. Regenerate the overlay patches against the new source.
#    Exits non-zero with the offending patch if upstream changed a patched
#    region — that (and only that) patch then needs re-deriving.
python3 scripts/gen-patches.py

# 4. Compose the work tree + rebuild + verify in the simulator
scripts/apply-overlay.sh
scripts/build-ios-core.sh ios-sim
(cd app && xcodegen generate && xcodebuild -scheme Apotris \
   -destination 'platform=iOS Simulator,name=iPhone 17' build)
scripts/sim-verify.sh          # unit + UI tests, screenshot artifacts

# 5. Ship it
scripts/build-ios-core.sh ios && scripts/build-ios-core.sh xros
scripts/publish-ota.sh         # updates the tailnet ipas + SideStore source
scripts/release.sh             # clean public commit + push to GitHub
```

## What usually happens

Most upstream changes are in game logic / assets and never touch our 9
patched regions, so steps 3–4 are a clean no-op re-pin and it "just works".
When a patch *does* need attention, `gen-patches.py` names the exact edit and
the mismatch, so re-deriving it is a targeted fix (see the patch's `gen(...)`
block in `scripts/gen-patches.py`).

The 9 patches, for reference:
`0001` meson apple-mobile target · `0002` platform.hpp IOS include ·
`0003` NO_ONLINE guards · `0004` `apotris_main` entry · `0005` audio stdio I/O ·
`0006` SoLoud CoreAudio backend · `0007` Tilengine no-OpenSSL ·
`0008` IOS default binds · `0009` native-HUD gate.

## Cadence

There's no automated watch — ping me ("Apotris has an update") whenever
akouzoukos cuts a release and I'll run this loop, verify, and re-publish. If
you'd rather it be automatic, I can add a scheduled job that checks the gitea
repo for new tags and opens the update for you.
